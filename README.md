# Hi there, I'm Daniel 👋

## 🎓 About Me

**Civil Mathematical Engineer** and **Master's in Data Science** graduate from [University of Chile](https://uchile.cl/english).

Currently working as a **Data Engineer at In-Data**, building end-to-end data infrastructure with a high degree of autonomy, from multi-source ingestion pipelines and Airflow orchestration to relational modeling and geospatial data with PostGIS.

I enjoy designing systems that are modular, maintainable, and solve real problems, whether that's a production pipeline integrating a dozen sources into a consolidated database, a spatial query engine for territorial analysis, or an open source tool for the remote sensing community.

Based in Santiago, Chile

## 💼 What I'm Working On

- 🔗 Integrating **heterogeneous data sources** (REST APIs, AJAX scraping, public datasets, satellite imagery) into consolidated, production-ready databases across multiple projects
- 🗺️ Building a **PostgreSQL + PostGIS** database to consolidate real estate transactions in Chile, enabling spatial queries
- 🔍 Developing a configurable **data observability system** with automated HTML reports and role-based alerting, backed up to AWS S3
- 🛰️ Built time-series deep learning models for **construction state classification** from satellite imagery: three model variants sharing a common architecture (image encoder → LSTM → CRF), differing in their image encoder: **pixel statistics**, **Pixel Set Encoder**, and **CNN**. Unified under a base class with pluggable encoders and a shared training pipeline
- 🕷️ Built production scrapers combining **REST APIs, Playwright interception, and stateful AJAX scraping** (ASP.NET ViewState parsing via `requests`) to extract data from sources with no public API

### 🛰️ [Sentinel Images Downloader](https://github.com/DanielMinaya1/Sentinel-Images-Downloader)
Python library for automated download of Sentinel-1 and Sentinel-2 imagery from the Copernicus ecosystem. Supports AOI footprints, tile IDs, band selection, and date ranges. Installable via `pip`. Used in production pipelines for territorial analysis.
